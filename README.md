# Zender Books - Author Page

A modern, responsive author portfolio website built with HTML, CSS, and JavaScript.

## Features
- **Modern Design:** Glassmorphism UI, sleek typography, and dynamic animations.
- **Responsive Layout:** Optimized for both desktop and mobile devices.
- **Book Showcases:** Dedicated pages for featured books like *Muñeca*, *Nick Search*, and *Real Family*.

## Tech Stack
- HTML5
- CSS3 (Vanilla, custom properties, Flexbox/Grid)
- Vanilla JavaScript

## Project Structure
- `modern-site/` - Contains the main website source code.
  - `css/` - Styling and theme configurations.
  - `js/` - Interactive functionality and animations.
  - `images/` - Book covers, character art, and backgrounds.
  - `*.html` - Individual page templates.
